# Explicit local candidate admission

SWOS may use the user-authorised temporary local-bootstrap exception to admit exact
local Python packages and eligible HG-expressed application refinements. It retains
explicit temporary provenance; it does not grant formal approval.

A Capability instance's name is an ordinary HG Property. Inputs and outputs are HG
types discovered and validated at registration. Python strings, parameter names,
callable addresses and result adaptation belong to implementation packaging and SWC.
They require no additional HG binding layer. HG Property and relationship constraints,
including cardinality, remain valid under their governing law.

SWOS verifies the selected HG basis and retains the manifest, exact implementation
and test bytes, and dependency bytes for callable packages. It no longer copies HG's
legacy implementation_ref or requires Python argument names to equal HG port names.
Physical entry-point and context checks remain. Packaging executes no candidate code
or tests, and test-source presence does not prove success.

The minimal candidate.toml subset excludes imports, classes, module execution,
decorators and defaults. callable.toml supports explicit dependency snapshots and
physical context parameters. SWC must support the chosen adapter before invocation.

SWOS selects exact eligible implementation IDs. SemanticWorld reconstructs that
selection and owns catalogue/instance queries and Recruitment. SWC binds and invokes.
Candidate files, stored records and configuration alone confer no execution authority.

Changes to manifest paths, sources or test artifacts produce different package
identities. Previous admissions and evidence cannot silently cover them. The
registration-alignment snapshots under .history are historical provenance only.

## Current limitations

Manifest paths now use node/capability directly. The application proposal files still
contain excluded recursive port structures and depend on replacement HG registration
meaning. Renaming paths does not make those proposals admissible.

The current default test run retains five failing integration suites. Standalone
algorithm tests do not verify admission or operational runtime compatibility. See
[the migration record](MIGRATION.md) and [application status](applications/README.md).

Protected local typed commits exist in SemanticWorld under SWOS authority; current
candidate integration still needs migration. Formal founding and normal admission,
trusted evidence collection and further applicable Policy work remain outstanding.
